# TPINT_GRUPO_6_PR3 🩺  

Como parte del **Trabajo Integrador Final de Programación III**, desarrollamos un **sistema de gestión para una clínica médica** utilizando **C# con ASP.NET WebForms** y **SQL Server** como base de datos.  

## Descripción  
El sistema permite administrar la información de pacientes, médicos y turnos, integrando seguridad y buenas prácticas de desarrollo mediante una arquitectura en capas.  

## Funcionalidades principales  
- 🔐 **Login con 2 roles**: administrador y médico  
- 👨‍⚕️ **CRUD** para la gestión de pacientes, médicos y turnos  
- 🏗️ **Arquitectura en capas** (Datos, Entidades, Negocio y Vistas) para una estructura limpia y escalable  
- ⚙️ Uso de **procedimientos almacenados, validaciones y manejo de sesiones** para reforzar la seguridad y la lógica del sistema  

## Tecnologías utilizadas  
- C#  
- ASP.NET WebForms  
- SQL Server  
- HTML / CSS
